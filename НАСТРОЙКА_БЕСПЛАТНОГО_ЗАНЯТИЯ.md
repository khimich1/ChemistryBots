# Настройка функции "Бесплатное занятие"

## Что изменилось

Кнопка "📞 Бесплатное занятие" теперь работает функционально:

1. **Показывает информацию** о бесплатном занятии
2. **Предоставляет две кнопки:**
   - "📝 Записаться на занятие" - отправляет заявку в чат поддержки
   - "📞 Написать преподавателю" - прямая ссылка на преподавателя

## Настройка

### 1. Переменная окружения TRIAL_CHAT_ID

Добавьте в файл `.env` или настройте переменную окружения:

```bash
TRIAL_CHAT_ID=123456789
```

Где `123456789` - это ID чата (группы или канала), куда будут приходить заявки.

### 2. Username преподавателя

В файле `govr_bot/bot/handlers/menu.py` замените `@chemistry_tutor` на реальный username преподавателя:

```python
[InlineKeyboardButton(text="📞 Написать преподавателю", url="https://t.me/ВАШ_USERNAME")]
```

### 3. Как получить ID чата

1. Добавьте бота в группу/канал
2. Отправьте сообщение в группу/канал
3. Перейдите по ссылке: `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
4. Найдите `"chat":{"id":123456789}` - это и есть нужный ID

## Как это работает

1. **Пользователь нажимает** "📞 Бесплатное занятие"
2. **Бот показывает** информацию о занятии и две кнопки
3. **При нажатии "Записаться":**
   - Бот отправляет заявку в чат поддержки
   - Показывает подтверждение пользователю
   - Закрывает inline-клавиатуру
4. **При нажатии "Написать преподавателю":**
   - Открывается чат с преподавателем
