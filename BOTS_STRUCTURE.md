# Структура и работа Telegram ботов проекта ChemistryBots

## 📋 Общий обзор

Проект ChemistryBots состоит из трех взаимосвязанных Telegram ботов для изучения химии:

1. **`govr_bot`** - Основной бот для учеников
2. **`parent_bot`** - Бот для родителей учеников  
3. **`prepod_bot`** - Бот для преподавателей

---

## 🎓 govr_bot (Основной бот для учеников)

### Назначение
Основной образовательный бот для изучения химии. Предоставляет тесты, теоретические материалы, карточки для запоминания и отчеты о прогрессе.

### Структура проекта
```
govr_bot/
├── bot/
│   ├── handlers/           # Обработчики команд и сообщений
│   │   ├── __init__.py
│   │   ├── menu.py        # Главное меню
│   │   ├── tests.py       # Тестирование
│   │   ├── theory.py      # Теоретические материалы
│   │   ├── flashcards.py  # Карточки для запоминания
│   │   └── report.py      # Генерация отчетов
│   ├── services/          # Бизнес-логика
│   │   ├── __init__.py
│   │   ├── pdf_generator.py    # Генерация PDF отчетов
│   │   ├── report_cli.py       # CLI для генерации отчетов
│   │   ├── spreadsheet.py      # Работа с Google Sheets
│   │   ├── answer_db.py        # База данных ответов
│   │   └── flashcards_db.py    # База данных карточек
│   ├── utils/             # Утилиты
│   │   ├── __init__.py
│   │   └── topics.py      # Список тем химии
│   └── main.py           # Точка входа
├── Fonts/                # Шрифты для PDF
├── venv/                 # Виртуальное окружение
├── requirements.txt      # Зависимости
└── run_bot.sh           # Скрипт запуска
```

### Основные функции

#### 🧪 Тестирование
- **28 типов тестов** по разным темам химии
- **19 вопросов** в каждом тесте (формат ЕГЭ)
- Система оценки и статистики
- Сохранение прогресса в базе данных

#### 📚 Теоретические материалы
- Структурированные лекции по темам
- Интерактивные вопросы после каждого блока
- Отслеживание прогресса изучения

#### 🃏 Карточки для запоминания
- Флэш-карточки по категориям (INORG/ORG)
- Алгоритм повторения с интервалами
- Статистика запоминания

#### 📊 Отчеты
- PDF отчеты с детальной статистикой
- Графики прогресса по темам и тестам
- Диаграммы успеваемости по карточкам

### База данных
Использует `shared/test_answers.db` с таблицами:
- `test_answers` - ответы на тесты
- `theory_task_answers` - ответы на теоретические вопросы
- `user_profiles` - профили пользователей
- `flashcards_seen` - просмотренные карточки
- `flashcards_practice_log` - лог практики карточек
- `flashcards_errors` - ошибки в карточках

## 👨‍👩‍👧‍👦 parent_bot (Бот для родителей)

### Назначение
Позволяет родителям отслеживать прогресс своих детей в изучении химии и получать отчеты об успеваемости.

### Структура проекта
```
parent_bot/
├── bot/
│   ├── handlers/
│   │   ├── __init__.py
│   │   └── menu.py        # Главное меню и отчеты
│   ├── services/
│   │   ├── __init__.py
│   │   ├── db.py                      # База данных родителей
│   │   ├── gpt_service.py             # Интеграция с GPT
│   │   ├── filename_generator.py      # Генерация имен файлов
│   │   ├── check_online.py            # Проверка онлайн статуса
│   │   └── backfill_user_profiles.py  # Заполнение профилей
│   └── main.py
├── logs/
├── venv/
├── requirements.txt
└── run_bot.sh
```

### Основные функции

#### 🎯 Онбординг
- Регистрация родителя (имя, фамилия)
- Привязка к аккаунту ребенка по Telegram username
- Сохранение связей в локальной БД

#### 📊 Отчеты об успеваемости
- Получение PDF отчетов о прогрессе ребенка
- Использует данные из основной базы `test_answers.db`
- Генерация через CLI модуль `govr_bot`

#### 🤖 GPT Ассистент
- Интеграция с OpenAI GPT для консультаций
- Контекстные ответы с учетом роли родителя
- История последних 20 сообщений

#### 💳 Система оплаты
- Заглушка для будущей интеграции платежей
- Планируется добавление оплаты занятий

### База данных
Использует `parent_bot/users.db`:
- `users` - профили родителей и привязки к детям

## 🗃️ Общие ресурсы

### Shared директория
```
shared/
├── test_answers.db        # Основная база данных
├── tests1.db            # База вопросов для тестов
├── users.db             # База пользователей parent_bot
├── prepared_lectures.db  # База лекций
└── __pycache__/
```

### Ключевые таблицы в test_answers.db

#### test_answers
Хранит все ответы на тесты:
```sql
CREATE TABLE test_answers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,           -- Telegram user_id
    username TEXT,             -- Telegram username
    answer_time TEXT,          -- Время ответа
    test_type INTEGER,         -- Тип теста (1-28)
    question_id INTEGER,       -- ID вопроса
    question_text TEXT,        -- Текст вопроса
    user_answer TEXT,          -- Ответ пользователя
    correct_answer TEXT,       -- Правильный ответ
    is_correct INTEGER,        -- 1 если правильно, 0 если нет
    full_name TEXT            -- ФИО пользователя
);
```

#### user_profiles
Профили пользователей:
```sql
CREATE TABLE user_profiles (
    user_id INTEGER PRIMARY KEY,
    username TEXT,
    full_name TEXT,
    created_at TEXT,
    hide_reason TEXT
);
```

#### theory_task_answers
Ответы на теоретические вопросы:
```sql
CREATE TABLE theory_task_answers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    username TEXT,
    topic TEXT,                -- Тема
    chunk_idx INTEGER,         -- Индекс блока
    question_index INTEGER,    -- Индекс вопроса
    question_text TEXT,
    answer_text TEXT,
    answer_type TEXT,          -- Тип ответа
    voice_file_id TEXT,        -- ID голосового сообщения
    created_at TEXT,
    is_correct INTEGER,
    feedback TEXT
);
```

## 📊 Система отчетов

### PDF Генератор
Все боты используют единую систему генерации PDF отчетов:

#### Структура отчета
1. **Титульная страница** - имя ученика, дата
2. **Общий прогресс** - два круговых графика (карточки + тесты)
3. **Прогресс по темам** - список тем с галочками + процентная шкала
4. **Прогресс по тестам** - горизонтальные столбцы по 28 тестам
5. **Прогресс по карточкам** - детальная статистика по категориям

#### Динамические имена файлов
- Формат: `Имя_Фамилия_ДД.ММ.ГГГГ.pdf`
- Приоритет имен: БД → Telegram full_name → username → "Ученик"

## 🚀 Запуск и развертывание

### Требования
- Python 3.8+
- SQLite3
- Токены Telegram ботов
- API ключи (OpenAI для parent_bot)

### Запуск каждого бота

#### govr_bot
```bash
cd govr_bot
source venv/bin/activate
python main.py
```

#### parent_bot
```bash
cd parent_bot
source venv/bin/activate
python bot/main.py
```

#### prepod_bot
```bash
cd prepod_bot
source venv/bin/activate
python main.py
```

### Переменные окружения
Каждый бот использует `.env` файлы для конфигурации:
- `BOT_TOKEN` - токен Telegram бота
- `OPENAI_API_KEY` - ключ OpenAI (для parent_bot)
- `TESTS_DB_PATH` - путь к базе тестов
